# Third-party models and libraries

This repository contains only scripts (MIT). The models are downloaded at run time from Hugging Face and keep their own licenses.

|---|---|---|

| CLAP (HTSAT, unfused) | https://huggingface.co/laion/clap-htsat-unfused (Wu et al., *Large-scale Contrastive Language-Audio Pretraining*, ICASSP 2023) | Apache-2.0 |
| AudioSet ontology / class names | https://research.google.com/audioset/ | CC BY 4.0 |
| librosa | https://librosa.org | ISC |
| PyTorch, Transformers, soundfile, NumPy, imageio-ffmpeg | PyPI | BSD / Apache-2.0 / BSD / BSD / BSD |
| ffmpeg (system or imageio-ffmpeg binary) | https://ffmpeg.org | LGPL/GPL |
